# NXO TECH

Front end de una tienda online de tecnología (auriculares, parlantes, power banks, smartwatches y accesorios). Diseño mobile-first hecho con HTML y Tailwind CSS (por CDN).

## Archivos

- `index.html`: la página completa.
- `DESIGN.md`: guía de diseño (colores, tipografías, espaciados).
- `screen.png`: captura del diseño.
- `serve.ps1`: servidor local en PowerShell (Windows).

## Verlo en local

Abrir `index.html` en el navegador, o levantar un servidor en Windows:

```powershell
powershell -ExecutionPolicy Bypass -File serve.ps1 -Port 8080
```

y entrar a http://localhost:8080

## Publicarlo con GitHub Pages

En el repositorio: **Settings → Pages → Branch: `main` / `(root)` → Save**.
